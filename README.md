# Semantic Search with Vector Embeddings

Semantic search with vector embeddings works by transforming text into numerical representations that encode semantic relationships. By comparing the similarity between a query vector and document vectors, the most relevant documents can be retrieved, mirroring the core functionality of vector databases.

## Language

`python`

## How to Run

1. Install dependencies: `pip install sentence-transformers torch scipy`
2. Run the script: `python main.py`

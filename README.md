# Semantic Search with Vector Embeddings

This example demonstrates how to perform semantic search using vector embeddings. It converts text into numerical vectors that capture semantic meaning, then calculates the similarity between a query and a set of documents to find the most relevant ones, mimicking the core concept of vector databases.

## Language

`python`

## How to Run

1. Install dependencies: `pip install sentence-transformers torch scipy`
2. Run the script: `python main.py`
